# plainsmansoftware.com

A static site: no build step, no trackers, no cookies. Built for GitHub Pages.

- `/` is the Plainsman Software home page.
- `/marginmark/` is the product page, with pricing.
- `/marginmark/support/`, `/marginmark/privacy/` and `/marginmark/terms/` are the support and legal pages.
- `404.html`, `CNAME`, `robots.txt` and `sitemap.xml` are for hosting and search.

## Editing

The pages are generated by `build.py`, which isn't published with the site. Prices, emails, the address and the Chrome Web Store link are constants at the top of that file.

1. Edit the constants or the page text.
2. Run `python build.py`.
3. Commit the `site/` folder.

The install buttons say "Get notified at launch" until you paste the store link into `CHROME_STORE_URL`.

## Publishing on GitHub Pages

1. Put the contents of this folder at the root of the public repo `PlainsmanSoftware/plainsmansoftware.com`, then push.
2. In the repo, go to **Settings → Pages**. Set the source to **Deploy from a branch**, with branch `main` and folder `/ (root)`.
3. Set the custom domain to `plainsmansoftware.com`, and tick **Enforce HTTPS** once it becomes available.
4. In Squarespace DNS, change only the website records:
   - Replace the apex `@` A records with `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`.
   - Point `www` with a CNAME to `plainsmansoftware.github.io`.

   Leave the MX, SPF, DKIM, DMARC, Google verification and `api-lle` records untouched.
